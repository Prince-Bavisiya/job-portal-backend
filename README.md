# Job Portal Backend API

A Job Portal Backend built using Node.js, Express.js, MySQL, JWT Authentication, bcrypt, Validation Middleware and Role-Based Authorization.

## Features

- User Registration & Login
- JWT Authentication
- Password Hashing
- Job CRUD Operations
- Apply For Jobs
- View Applicants
- Application Status Management
- Search Jobs
- Pagination
- Rate Limiting

## Tech Stack

- Node.js
- Express.js
- MySQL
- JWT
- bcrypt

## Run Project

npm install

npm run dev
